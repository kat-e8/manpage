The .env File on Clubuntu

The last piece docker-compose.deploy.yml needed. Generated and written in one step, entirely on clubuntu — the actual values never passed through this session, this laptop, or git at all.

file: /opt/docker/manpage/.env 2026-08-16
01

Why it was necessary

Every ${VAR} in docker-compose.deploy.yml is a placeholder — Compose fills it in from environment variables, and .env in its working directory is where those come from automatically. Without one, every placeholder resolves to an empty string; postgres would start with no user, no password, no database name.

02

One value needed a real decision: GATEWAY_HOST_PORT

Clubuntu already runs a dozen other projects under /opt/docker/, so the dev laptop's default port wasn't safe to assume free. Checked first:

$ ssh clubuntu ... "ss -tln"
:5000 in use — the private registry itself, expected
:8100 — not listed, free
→ GATEWAY_HOST_PORT=8100, same as dev, confirmed safe rather than assumed
03

The password — generated, never transmitted

Copying schema.sql and coder_commands.xlsx (doc 6) meant those bytes genuinely traveled over the network, just encrypted. A password is more sensitive still — the safest transfer is the one that never happens. openssl rand ran on clubuntu itself, inside the same SSH session, so the value was generated, used, and written to disk without ever existing on this laptop or crossing the network as a distinct step.
