What this actually tests

Doc 9 proved build — code in, images in the registry. It never touched a running container. This is the other half: a tag resolving to a commit, that commit's already-built images getting pulled (not rebuilt), and the stack actually coming up on clubuntu. The whole reason every push builds and only a tag deploys, from the very first planning doc, was to make this moment cheap and safe rather than something to be nervous about.
